## Reporting a Vulnerability

We take the security of Resonance and its execution runtime seriously. If you discover a security vulnerability (such as observation leakage, sandbox escape, malicious payload deserialization, or denial-of-service via resource exhaustion), please report it responsibly.

### How to Report
- **Email:** Please report security issues directly to the maintainer at **amirlankalmukhan1@gmail.com**.
- **GitHub Private Advisory:** Alternatively, use GitHub's private vulnerability reporting feature on this repository.
- **Do NOT** file public GitHub issues for sensitive security vulnerabilities.

### What to Include
Please include:
1. Description of the vulnerability and attack vector.
2. Step-by-step reproduction instructions or a minimal proof-of-concept script.
3. Impact assessment on the host system or environment runtime.
4. (Optional) Proposed remediation or patch.

### Response Timeline
- We will acknowledge receipt of your vulnerability report within 48 hours.
- We will provide an assessment and timeline for a patch within 5 business days.
- We will coordinate public disclosure after the fix has been merged and verified.

Thank you for helping keep Resonance safe and reliable for the scientific community!
