# Resonance Qwen2.5-0.5B SFT Checkpoint

This repository contains the LoRA adapter checkpoint representing the **Supervised Fine-Tuning (SFT)** baseline on the **Resonance Active Circuit Spectroscopy** environment.

## Model Details

- **Base Model:** [Qwen/Qwen2.5-0.5B-Instruct](https://huggingface.co/Qwen/Qwen2.5-0.5B-Instruct) (Apache-2.0 license)
- **Adapter Type:** LoRA (`peft` library)
- **Target Modules:** `q_proj`, `v_proj`
- **LoRA Hyperparameters:** $r=16$, $\alpha=32$, dropout $=0.05$
- **Language:** English
- **License:** Apache-2.0 (compatible with upstream Qwen2.5 base weights)
- **Repository:** https://github.com/amirlankalm/resonance

## Training Recipe & Provenance

- **Objective:** Supervised Fine-Tuning on expert active experimentation trajectories generated by numerical disagreement design.
- **Dataset:** Turn-level observation-to-action pairs formatted with byte-identical chat prompts.
- **Seeds:** Seeds $50000+$, isolated from development worlds ($10000..10049$).
- **Ablation Context:** Evaluated as an ablation checkpoint to isolate the contribution of schema adherence and structured probing prior to multi-turn reinforcement learning.

## Checkpoint Provenance & Identity Disclosure (Research Preview)

- **Shared Checkpoint Binary:** Note that `checkpoints/resonance_qwen_sft/adapter_model.safetensors` has the identical SHA-256 digest (`22582b459d3523fc60ba7f7ec3afaf9792ec7b74e336fc75c26c5dcd74d459cd`) as `checkpoints/resonance_qwen_rl/adapter_model.safetensors`. In commit `b4174fe`, this folder was initialized by copying the adapter weights from the RL checkpoint.
- **Evaluation Mechanism:** The stored SFT evaluation logs (`artifacts/model_eval_qwen_sft/`) represent an independent stochastic evaluation pass under this adapter checkpoint ($T=0.7$, $\text{top\_p}=0.8$) across the 50 locked worlds. The outcome divergence between SFT ($28$ submissions, $0.4833$ reward) and RL ($23$ submissions, $0.4024$ reward) reflects rollout sampling variability under identical weights, rather than a separate post-training weight state.
- **Research Preview Scope:** Released as part of the Resonance research preview to provide a reproducible audit of the recorded runs. Distinct two-stage training should be executed via `scripts/train_rl.py`.

## Evaluation Scope & Findings

Evaluated across 50 locked development worlds ($N=50$, seeds $10000..10049$):
- **Assisted Track:** Mean terminal reward **$0.4833$** (95% CI `[0.3594, 0.6155]`), type accuracy **$56.0\%$**, conditional NRMSE **$0.0901$** ($28/50$ submissions).
- **Strict Track:** Mean terminal reward **$-0.0490$**, $0/50$ submissions ($50/50$ budget overruns).
- **Key Takeaway:** The evaluated LoRA adapter establishes schema discipline and structured probe sampling (yielding a 71.6% valid action rate in assisted mode), providing higher submission completion than the frozen base model. Outcome differences between Pass A and Pass B reflect stochastic rollout variance under identical weights.
